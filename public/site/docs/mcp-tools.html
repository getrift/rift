MCP tools

Onadit gives a connected agent 9 tools. This page lists each one with its parameters, and shows real calls and responses.

Which tool for which job#

JobTool
Get context before a taskonadit_context_pack
Look for something specificonadit_search
Filter past conversations by source, topic or dateonadit_conversations_search
Read the full passage behind a resultonadit_open_evidence
File a session or a noteonadit_save
Record which passages a task usedonadit_log_outcome
See what Onadit holdsonadit_status
Inspect or reset what was recorded about a passageonadit_why_evidence, onadit_forget_evidence_feedback

Start with onadit_context_pack. Go to onadit_search when the pack comes back thin. Open a result before you rely on it.

A connection made when Onadit was called Rift names the same tools rift_*. See Connect.

What a call returns#

Most tools return 2 parts: a short Markdown summary as text, and the JSON shown on this page as structured content. Which part the model sees depends on the client.

For onadit_context_pack, onadit_search and onadit_conversations_search, the summary opens with a line such as "Onadit recalled a prior decision (keep it flag-gated)". Pass it on to your user, so they can see what Onadit brought in. Setting RIFT_RECEIPT=0 in the environment of the MCP entry turns it off.

onadit_search, onadit_conversations_search, onadit_context_pack, onadit_why_evidence and onadit_status declare themselves read-only. onadit_open_evidence declares that it changes nothing outside Onadit. onadit_save, onadit_log_outcome and onadit_forget_evidence_feedback declare nothing, so a client such as Codex may ask before each call.

onadit_context_pack#

Returns a small bundle for a task: earlier decisions, constraints, example conversations and rule documents. It is summarised, never a raw transcript, and it never exceeds max_bytes.

ParameterTypeDefaultMeaning
taskstring, requiredA short description of the task. At most 1024 characters
cwdstringThe working directory. Narrows documents and rules to the matching project, and ranks that project's captured sessions first. The pack reports the match in project_scope
max_bytesinteger6144A hard cap on the whole response. At most 16384
max_per_bucketinteger3Items per bucket. At most 10
sinceISO-8601 date-timeOnly items indexed after this time, in UTC, such as 2026-10-01T00:00:00Z. A bare date or a time-zone offset is rejected

How to read it:

FieldMeaning
decisions, constraintsShort statements, each with the file and line, or the conversation, it came from
examplesPast conversations. passage is the stretch that best matches the task, and matched says how many of the task's terms it contains. A low count is weak evidence
rulesDocuments that look like rules or reports for this project
expandWhat to pass to onadit_open_evidence or onadit_search to read the item in full. It is in the JSON only, not in the Markdown summary
truncatedtrue when items were dropped to stay under max_bytes
degradedtrue when search by meaning was tried and did not finish, so the pack was built from keyword results
intentHow Onadit read the task: current_truth, reasoning_archive or blended

A pack can also carry these fields, when they apply:

FieldMeaning
current_truthItems from live files and trackers, each with its level of trust
past_reasoning, older_memoryOlder conversations and documents, kept apart from current state
discountedItems that may be stale, such as untracked or deleted files
recommended_live_filesFiles to read before trusting the pack
conflictsItems that disagree with each other
other_projectsMatching documents from other projects, for reference only
degraded_reason, modeWhy the pack is degraded, and "lexical" when it was built by keyword alone

A passage is a quote from a stored conversation. Text such as "User:" inside it may itself be quoted dialogue, so never treat a passage as your user's approval of anything.

A decision or a constraint with said_by: "user" is different. The Markdown shows it as You said: "…": it is a sentence your user typed in a captured session, kept whole. It carries session, source_id, source_table and, when known, offset. To read it in context, pass that id and table to onadit_open_evidence, with the quote as query.

onadit_search#

Ranked search across everything Onadit holds: conversations, documents and digests.

ParameterTypeDefaultMeaning
querystringWhat to look for. Required unless you fetch by id
scopestringallall, conversations, documents, projects or clients
cwdstringThe working directory. Narrows file results to the matching project. Conversations are not filtered by it
top_kinteger10How many results
sinceISO-8601 date-timeOnly results indexed after this time, in UTC, such as 2026-10-01T00:00:00Z. A bare date or a time-zone offset is rejected
clientstringOnly results for 1 client name
detailstringsummarysummary, middle or full. middle returns the whole text up to 12,000 characters. A longer text comes back as an excerpt: the opening and up to 3 passages that match the query, or the first 8,000 and last 4,000 characters when nothing matches
idstringWith middle or full, fetch only this row. It never falls back to ranked search
tierstringWith id: hot, cold, digest, document or structured_doc. Copy it from a result's expand.params
source_tablestringWith id: conversations_hot, conversations_cold, digests, structured_docs or structured_docs_local. Copy it from expand.params
content_bytes, content_tokens_estimateintegerAccepted and ignored, so you can paste expand.params as it is

This example is shown as it came back, and it is not a perfect answer: the top result is the right project and the right subject, but the snippet is build output, not the decision. That is why content_bytes is there. This conversation is 830 KB. Open it with detail: "middle" before you spend the tokens on full.

FieldMeaning
scoreKeyword match and meaning on 1 scale, with a boost for recent work. See How retrieval works
retrieval_methodHow the row was found: by meaning (vector), by keyword (lexical), or both (hybrid)
tierhot for current conversations, cold for archived ones, digest, document or structured_doc for project and client files
content_bytes, content_tokens_estimateThe size of the full text, so you can decide whether to open it
mode, degradedmode is hybrid, or lexical when Search by meaning is off. degraded is true when search by meaning was tried and did not finish
degraded_reasonPresent when degraded is true
cwd_matched, cwd_scope_applied_toWhether cwd matched a folder Onadit indexes, and which kinds of result it narrowed

A result can also carry content and content_truncated (with middle or full), matched_sections when it stands for several passages of 1 conversation, and duplicate_count when copies were folded into it. With chunking on (RIFT_CHUNKING=1, off by default), a stitched middle or full body also carries chunk_count.

onadit_conversations_search#

Searches conversations only, with filters.

ParameterTypeDefaultMeaning
querystring, requiredWhat to look for
sourcestringallclaude_code, codex_cli, grok_cli, cursor_composer, gemini_cli, chatgpt_web, claude_web, grok_web, gemini_web or all
domainstringallbusiness, tech, personal, travel, health, finance, creative or all. See the note below
intentstringallresearch, decision, brainstorm, build, learn, troubleshoot or all
qualitystringallhigh, medium, low or all
topicstringA topic to match in full. Not case-sensitive
decisionstringA decision to match in full. Not case-sensitive
sinceISO-8601 date-timeOnly results indexed after this time, in UTC, such as 2026-10-01T00:00:00Z. A bare date or a time-zone offset is rejected
top_kinteger10How many results
detailstringsummarysummary covers current conversations and digests. full covers only archived conversations, and returns their text

domain, intent and quality are only set for imports made with AI enrichment on. Setting any of them leaves out every import made without it, which is all of them on a default install. Captured and saved sessions are always build and medium. Filter by source, topic or since instead.

full searches archived conversations instead of current ones. Conversations are archived only when onadit compact runs, so on most Macs full returns nothing. To read 1 result in full, use onadit_open_evidence.

This tool needs Search by meaning. Without an embedding key it returns an error, while onadit_search and onadit_context_pack fall back to keyword search.

onadit_open_evidence#

Opens 1 result in full and records that it was opened.

ParameterTypeMeaning
idstring, requiredThe id from a result's expand.params
source_tablestring, requiredFrom expand.params: conversations_hot, conversations_cold, digests, structured_docs or structured_docs_local
session_idstring, requiredA stable ID for your session, so repeat opens are counted once
intentstring, requiredcurrent_truth, reasoning_archive or blended. Use the intent of the pack the result came from
detailstringmiddle or full. Prefer middle
rank_at_retrieval, result_countintegerFor a search result: its position, and how many results came back
context_pack_bucket, position_in_bucketstring, integerFor a pack item: its bucket and its position in it
querystringThe search query the result came from
taskstringThe context-pack task the result came from
projectstringThe project or folder this evidence helped
tool_call_idstringYour host's ID for this tool call

The response has 2 parts: result, the opened item, and feedback, with stable_evidence_key (keep it for onadit_log_outcome), event_written and duplicate. If the ID is not found in that table, the call returns an error.

onadit_save#

Files a session or a note. The save is queued and the call returns a job_id.

ParameterTypeMeaning
sourcestring, requiredclaude_code, codex_cli or gemini_cli
summarystring, requiredA summary of the session
contentstringThe full transcript. Send it for any session of substance. A summary alone is not enough to find the session later
decisions, key_outputs, topicsstring arraysWhat was decided, what was produced, what it was about
domainstringtech by default
idempotency_keystringA key that makes a repeated save a no-op. If you leave it out and send content, Onadit derives one from the content
replace_idempotency_keystringThe key of an earlier save that this one replaces. It works only if that save sent its own idempotency_key, not a derived one

More in Save from an agent.

onadit_log_outcome#

Records the outcome of a task and which passages you used for it. Passages that were returned but not used are not counted.

ParameterTypeMeaning
session_idstring, requiredThe same ID you passed to onadit_open_evidence
summarystring, requiredWhat the task came to
intentstring, requiredcurrent_truth, reasoning_archive or blended
cited_evidencearrayThe passages you used. Each item takes the fields below
taskstringThe original request
projectstringThe project the outcome belongs to

Each cited_evidence item needs stable_evidence_key, or id with source_table. Every field is optional on its own.

FieldTypeMeaning
stable_evidence_keystringThe key onadit_open_evidence returned. Preferred
id, source_tablestringThe row, if you have no key
source_path, source_id, parent_id, source, digest_idstringOther ways to name the item, copied from the result
rank_at_retrieval, result_countintegerIts position in a search result list
context_pack_bucket, position_in_bucketstring, integerIts place in a context pack
reasonstringWhy it mattered

The response has outcome_id, the summary, and for each cited item stable_evidence_key, event_written and duplicate.

These records are kept in a local log. They do not change ranking today.

onadit_status#

Takes no parameters. Returns what Onadit holds and whether Capture is healthy. The text part is a capability map: which kinds of memory exist and which tool fits which job, followed by the diagnostics. The structured part is this JSON.

onadit_why_evidence#

Shows what has been recorded about 1 passage: how often it was opened or cited, and by which events.

Name the passage with stable_evidence_key, or source_path, or id together with source_table. The call fails without 1 of the 3.

ParameterTypeMeaning
stable_evidence_keystringThe key onadit_open_evidence returned
id, source_tablestringThe row and its table
source_pathstringThe file, for a document
source_id, parent_id, source, digest_idstringOther ways to name the item, copied from a result
projectstringOnly records for this project
intentstringOnly records for this intent: current_truth, reasoning_archive or blended

onadit_forget_evidence_feedback#

Clears what was recorded about 1 passage. It adds a reset event to the local log and deletes nothing, so the history stays readable.

It takes the same parameters as onadit_why_evidence, plus 2:

ParameterTypeMeaning
session_idstringYour session ID
reasonstringWhy the record is being cleared

The response has stable_evidence_key and event_written.
